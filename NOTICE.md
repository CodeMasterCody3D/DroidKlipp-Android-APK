# Notices and Attribution

## Project Lineage

DroidKlipp Android APK is an open-source Android APK project forked from **XServer XSDL**.

The original XServer XSDL project is an Android port/package of X.Org X Server technology and related Android/SDL integration work. This repository keeps that lineage and license attribution intact while packaging the modified DroidKlipp APK used with DroidKlipp/KlipperScreen.
