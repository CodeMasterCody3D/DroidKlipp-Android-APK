# DroidKlipp Android APK

Android APK package for DroidKlipp's XServer XSDL integration.

This project is an open-source fork/package derived from **XServer XSDL**, the Android X Server project. DroidKlipp uses this APK as the Android-side X server target for DroidKlipp/KlipperScreen workflows.

## Download

Download the latest APK from GitHub Releases:

[Download DroidKlipp.apk](https://github.com/CodeMasterCody3D/DroidKlipp-Android-APK/releases/download/2.0.0/DroidKlipp.apk)

Release page:

https://github.com/CodeMasterCody3D/DroidKlipp-Android-APK/releases/latest

## Install

1. Download `DroidKlipp.apk` from the release link above.
2. Transfer it to your Android device if needed.
3. Enable installation from unknown sources for your browser/file manager.
4. Open the APK and install it.
